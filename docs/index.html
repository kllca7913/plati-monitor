每小时明细（北京时间，列标签为该时段结束时刻）

可左右滑动，新到旧排列。“—”表示该时段暂无数据（尚无上一次快照，或当次/上次有商品未取到，为避免误差不计算）。若两次快照间隔明显不是1小时，列标签带“*”。

  • 每小时数据（近似值）：每小时采集一次各卖家商品的“累计已售”计数器（同样按卖家合并所有面额），每小时新增 = 相邻两次快照的累计之差。
  • 每小时数据从首次每小时快照（）开始，之前没有数据；每小时采集与每晚 20:00 的日统计互相独立，两者数字可能不完全一致。
  • “24h合计”只对单个卖家，累加最近24小时内有数据的时段，并标注已覆盖的小时数；不同卖家之间不求和。
  • 数据说明（近似值）：数据来自 Plati 公开搜索接口中各商品的“累计已售”计数器，对每个卖家下固定的苹果礼品卡商品，按卖家合并所有面额后求和。
  • 每日新增订单 = 当晚 20:00 快照与上一日快照的累计销量之差，并非卖家后台的真实订单数。
  • 若某商品当次搜索未被返回，则不会计入该卖家，数字可能略偏低；“—”表示当天无对比数据（首日基线或缺数据）。
  • 各卖家之间不求和；美国卡与土耳其卡分开统计，同一卖家可能同时出现在两个榜单中（分别统计各自的商品）。
